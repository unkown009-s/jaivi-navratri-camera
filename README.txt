JAIVI NAVRATRI — CAMERA VERSION

VS CODE SETUP
1. Open this whole folder in VS Code.
2. Install the extension "Live Server" by Ritwick Dey.
3. Right-click index.html -> Open with Live Server.
4. The browser should open at http://127.0.0.1:5500/ (or similar).
5. Scroll to BEAUTY SCANNER and press START SCAN.
6. When Chrome asks for camera permission, click Allow.

IF CAMERA IS BLOCKED
Click the lock icon beside the browser address -> Camera -> Allow -> reload.

IMPORTANT
Do not use a plain file:/// URL for the camera scanner. Use Live Server in VS Code or HTTPS/GitHub Pages.
